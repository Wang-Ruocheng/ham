# 连续场 phi4 大尺寸对照

这是独立的新实验入口 `python -m scripts.run_phi4_qcr_large`，不修改已经完成的 L36 训练、报告、代码快照或二值 QCR 默认配方。新尺寸为 108→36→12；仍为 dimg=1、hidden96、float64、随机概率 C、三个独立 fresh Adam(.001)、3000 次更新、batch8×64 与两个目标尺度均匀权重。原连续场信息代理和各项 loss 均保持不变，代理的已知有限样本自点排除偏差也没有在本次偷偷修复。

采样仍为 u=1、h=0、11 个 r 点、每点四链、1024 轨迹预热、每8轨迹保存一次、每链128构型，总90112条 HMC 轨迹。大体积下原 .08/12 积分器冷初态接受率不适用，因此用户明确授权固定改为 .04/24，轨迹长度仍为 .96，作用量、Metropolis 校正及样本数不变。实际力格点计算次数为 26,276,659,200，上限明确设为27,000,000,000。不得把该数值积分细化掩饰为逐比特的单变量复现。

新实验在225的物理GPU3（固定UUID）执行；与旧实验GPU2不同，属于已披露的执行设备差异，不迁移任何既有训练或干预他人。准备计划后所有物理参数、资源预算和源码指纹冻结。默认CPU14400核秒、GPU7200卡秒、GPU自身峰值8GiB、实验目录2GiB；使用前检查共享主机CPU、内存、I/O及连续两次间隔至少10秒的GPU空闲状态。资源不足只等待。

父程序先对 r=-2,-.75,.5 的热初态和正负冷初态分别作独立数值预检：与生产相同的1024条预热轨迹，8个保存构型、间隔8，共每链1088轨迹。所有9链的生产接受率至少.6，且保守CPU预算通过后才开始正式物理采样。预检只验证数值可用性和吞吐，不认证平衡；不复用预检构型，不自动调步长、加样或换seed。正式采样后另以20步独立模型检查GPU吞吐与预算，再重新初始化正式模型进行3000步训练。

启动形式为 `--prepare --output NEW_ROOT`、`--launch --output NEW_ROOT`。可选尺寸、积分器及预算参数仅能在准备阶段指定，执行只读取与job指纹一致的冻结plan；既有目录永不覆盖、恢复或重跑。预算门控、低接受率或异常保留全部产物并等待用户，不降低样本或步数凑完成。全部阶段成功后只读公开数组生成中文R(g)、R(g)-g位移、r→g映射与loss曲线，公共白名单不含构型或checkpoint。

更大末端体积只检验有限尺寸影响，不保证已经消除临界慢化、采样偏差、信息代理偏差或一维坐标不闭合；所有原始诊断警告保留，thermal_nu仍为null。
