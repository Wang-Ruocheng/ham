## 论文标题

**Learning Renormalization Flows from Unlabeled Configuration Ensembles**  
《从无标签构型系综中学习重整化流》

## 摘要

介绍 Q–C–R 框架、独立梯度训练，以及“统计重构—跨尺度预测—普适标度识别”三个不同层次的目标。

## 1. 引言

### 1.1 RG 的成功与实际构造的困难

说明 RG 在普适类、临界标度和多尺度有效理论上的成功；区分理论的一般性与具体实施中的系统依赖。实际计算仍需选择粗变量、构造粗粒化、截断相互作用，并验证解析或数值近似。

### 1.2 机器学习重整化的进展

介绍 RSMI／神经互信息估计、Neural MCRG，以及尤亦庄与合作者的代表性工作：神经网络全息映射（Hu 等，2020）、基于生成模型和 RG 单调函数的 MLRG（Hou 与 You，2023）、标量场 RGFlow（Zhao、Fogler 与 You，2026）。承认这些工作已能够学习 RG 变换、流及部分临界性质。

### 1.3 尚待解决的问题与研究动机

现有方法的输入要求和学习对象不同：信息保留不自动提供闭合的系综坐标，作用量方法依赖可求值的能量／作用量，部分生成式框架依赖显式对称表示和 RG 流的结构假设。本文关注无参数标签、无需向学习器提供作用量的构型系综输入，寻求同时学习粗粒化、共享统计坐标与自治尺度流的简洁框架；不笼统声称此前不存在通用 MLRG 框架。

### 1.4 Q–C–R 框架与主要贡献

提出粗粒化与表示演化的闭环关系，说明平凡解问题及独立梯度设计，区分统计重构、跨尺度预测与普适标度识别的证据要求。

以上四项是引言的论述顺序，正文仍采用连续段落，不新增引言子标题。

## 2. 粗粒化的递归表示框架

### 2.1 构型系综与分布演化

定义构型系综、粗粒化诱导的分布演化，以及“无标签但已按制备条件分组”的输入假设。

### 2.2 C：可训练的局部随机粗粒化

用共享局部概率核生成粗尺度构型，说明随机初始化、跨位置与尺度共享，以及离散采样的梯度估计。

### 2.3 Q：共享系综编码器与统计读出

通过局部 patch 特征池化获得系综坐标，用共享仿射读出重构局部模式分布，并说明归一化及坐标可辨识性的限制。

### 2.4 R：跨尺度共享的自治映射

使用残差网络预测坐标的尺度演化，区分 R(g)、位移 R(g)−g 与完整 Jacobian。

## 3. 训练目标与独立梯度路由

### 3.1 有限系综的表示目标

Q 通过子集一致性稳定系综估计，通过局部统计重构避免无信息表示。

### 3.2 带缓冲区的经验信息保留

C 最大化粗变量与远处完整环境壳之间的经验互信息，说明估计方式及有限样本偏差。

### 3.3 C 的统计正则

引入逐系综方差防塌缩与均匀块保色项，并明确这些正则的物理假设和适用边界。

### 3.4 一步与微观起点多步闭环

R 拟合相邻尺度和从微观起点出发的多步预测；介绍等尺度权重与历史非均匀权重消融。

### 3.5 不同目标下的同时更新

Q、C、R 同时更新，但各自只接收对应目标的梯度；给出完整训练算法伪代码。

## 4. 闭环一致性能说明什么、不能说明什么

### 4.1 有限步预测与误差累积

给出闭环残差随递归迭代传播的误差界，区分训练内拟合和未见深度泛化。

### 4.2 坐标自由度与普适标度

说明正则坐标变换下不动点谱的不变性，以及将相关特征值解释为热临界指数所需的条件。

### 4.3 函数值精度不等于导数精度

说明低重构误差或低闭环误差不能单独保证 Jacobian、局部稳定性或物理响应准确。

## 5. 评价协议

### 5.1 数据划分、有限系综估计与可复现性

区分独立物理链、同链构型和 C 随机重复；明确冻结评价、子集均值编码及实验指纹记录。

### 5.2 坐标闭环与物理统计预测

分别报告逐路径 RMSE/NRMSE，将统计预测误差区分为坐标输运贡献与表示／读出贡献。

### 5.3 初始尺寸泛化与未见深度

区分更大初始格点上的迁移和额外粗粒化步数上的泛化；说明构型展示与定量预测的不同作用。

### 5.4 物理响应与相关方向识别

用 score 协方差、完整 DR、有限差分及有限物理扰动检验局部闭合，讨论响应秩、噪声和方向可辨识性。

### 5.5 基准范围与定量结果

说明 Ising 等离散格点基准，以及 loss、耦合到 g 的映射、流场、不动点支撑和采样诊断的报告要求。

本章目前主要规定“如何评价”，尚不是完整的实验结果章；定量表格、替换图片和具体性能结论仍待纳入。

## 6. 讨论

- 讨论独立梯度路由的优点和限制。
- 说明局部统计目标、互信息估计及正则项的适用边界。

## 7. 结论

总结无标签 Q–C–R 框架及其可检验性，强调普适标度信息需要独立的物理证据。
