# 二维 XY：当前 QCR 管线的圆周适配试验

模型为方格最近邻铁磁 XY，周期边界，H/J=−Σ cos(θᵢ−θⱼ)，K=J/T，J=kB=1。
角度连续，未离散成时钟模型；一次反射多团簇 sweep 扫描全部最近邻边。

## 理论与验收

参考 T_BKT/J≈0.893（K_bare≈1.120），不是精确解析值。
低温是幂律关联、涡旋束缚的准长程序临界相，高温涡旋解缚且关联指数衰减。
任意正温热力学极限自发磁化均为零。高温侧 ξ≈ξ₀ exp(b/√t)，t=T/T_BKT−1。
重整化刚度 K_R=Υ/T 与涡旋逸度 y 的低逸度方程为
d(K_R⁻¹)/dℓ=4π³y²，dy/dℓ=(2−πK_R)y。
y=0、K_R>2/π 是低温不动点线；边界端点是边际的。
2/π 是重整化刚度的临界值，不是微观耦合 J/T_BKT。
不能以孤立排斥子、普通幂律 ν 或 ln(b)/ln(λ_R) 验收 BKT。

首轮只有一个尺寸、一个训练种子、标量 g，目的是考察温度排序、尺度闭合、
低温区域是否出现缓慢流动。不能宣称恢复完整二维 (K_R,y) 流或精确识别 BKT。
总涡旋密度不是游离涡旋密度；单尺寸 Υ=2T/π 交点不是可靠 Tc 外推。

## 固定方案

- L54→18→6，b=3、d_g=1，seed91，1250次 Q/C/R 各一次同步独立更新。
- T/J=[.50,.60,.70,.78,.82,.86,.89,.92,.95,1,1.06,1.15,1.25,1.4,1.6]。
  每温度四条独立链，两热两冷；每链128构型；burn2048、间隔16个多团簇sweep。
  整温度点留出，40条TRAIN、20条TEST；保留ESS、冷热差异等诊断。
- 继承当前显式 φ4 local-Q 试验的自由增益仿射解码器、Q/C学习率.001、R学习率.003。
  此自由增益选择不修改包的默认单位列范数约定。
- Q 输入中心参考的相对 sin/cos 九点图案；全局旋转不变；局域MLP18→96→12→12，
  池化后12→96→1；重构三条相对角度的8³维软联合概率。共享Q和解码器。
- C 为随机初始化、可训练的中心参考角+MLP角偏移，叠加σ=.25的缠绕高斯噪声；
  SO(2)协变，无选核或预训练。镜像对称不硬编码。
- C 继承连续场信息项适配：缓冲1格、完整24点环境的圆周核平滑信息代理，权重−2；
  逐系综圆周方差防塌缩权重2；均匀块角度保持的缠绕高斯NLL权重1。
  该信息量有平滑偏差，**不称精确经验直方图MI**，不使用InfoNCE。
- Q损失重构10、微观/粗尺度子集一致性20/5；R为等目标尺度all_start_anchor，总权重10。
  无温度、刚度、涡旋或理论临界位置监督；无额外R-only、选根、挑checkpoint。
- 一次性弃用计时pilot后验证固定步数预算；整条管线硬上限1小时，采样保守投影≤1500秒，
  自用GPU≤8GiB、单CPU线程、nice10。严重采样警告停止训练前，不自动补样或缩短训练。
  GPU3两次间隔10秒空闲检查，不共享或干预他人进程。

## 2026-11-04 联合续训

用户要求继续原 XY 训练直到平台。显式配置为
`configs/xy2d_b3_local_g1_joint_continue_seed91.json`，入口仍为
`python -m recurrent_rg train --config ... --output NEW_ROOT`，监督器为
`scripts.run_xy_qcr_continue`。保留1250步源模型、全部Adam动量和时钟；
Q/C/R均继续更新，数据、划分、模型、学习率和目标不变。
源checkpoint未保存RNG，因此使用已披露的新固定抽样流；续训checkpoint保存RNG。

每250步在全部40条TRAIN物理链的固定32构型和两组固定C随机数上评估。
至少追加2000步，连续三次确认相邻四探针窗口（约1000步）的绝对闭环损失与
当前TRAIN标准差归一化闭环误差均变化不足5%，且近期变异系数低于15%，才标记
操作性平台。该判据不证明Q/C静止、全局最优或BKT结构正确。
另记录相邻探针的各尺度编码漂移、C条件均值角度变化，以及旧R面对新Q/C目标时的误差。
TEST、温度、理论相变位置和数值根不参与停止选择。

本轮上限追加6000步、墙时1小时；若先到上限，报告中保持
`train_plateau_reached=false`，不冒称收敛。原运行、数据和代码快照不覆盖。

## 2026-11-05 固定 Q/C 的末尾 R-only 阶段

用户授权今后的新管线默认追加此阶段，并给上述 d_g=2、1250步联合训练补跑。
配置 `configs/xy2d_b3_local_g2_terminal_R_seed91.json`，监督器
`scripts.run_xy_qcr_g2_r_only`。保留已完成联合训练全部结果；从其最终权重与
R 的 Adam 状态开始，Q/C 零更新，学习率仍为 .003，等尺度 all-start 目标不变。
只用原40条 TRAIN 物理链，每链固定8组32构型子集及 C 实现，缓存两半均值编码；
320行缓存不是320条独立物理链。R 每次对全缓存均值做一次 Adam 更新。
这是从联合训练的在线目标抽样改为固定有限缓存，不是追加物理采样。

最多额外10000步，每500步测量固定 TRAIN 损失。至少3000步后，连续三次确认
过去2000步最佳损失改善小于1%，且当前损失距离最佳不超过5%，才记操作性平台；
到步数上限必须单独注明。温度、TEST、数值根和理论值不参与停止。

一次弃用计时副本含2步预热及8步计时，正式R及其Adam不受影响。
