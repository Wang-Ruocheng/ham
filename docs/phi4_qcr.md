# 连续场 phi4 QCR 首轮小实验

这是用户明确授权的连续场专用配方，不修改二值自旋实验的默认设置。物理作用量、单位、固定 HMC 和采样诊断沿用 [phi4.md](phi4.md)。研究正测度欧氏实标量场，不是实时复权重路径积分，也不解决符号问题。

## 冻结的首轮设置

- 二维周期 L36，非重叠 3×3 概率 C，36→12→4；潜坐标 dimg=1，hidden96，float64。
- 固定 u=1、h=0，r=-2,-1.75,…,.5 共 11 点；每点四条独立物理链，热初态两条、正负有序初态各一条。预热 1024 条 HMC 轨迹，每 8 轨迹保存一次，共 128 个构型。总 90,112 条轨迹。不是格点 sweep。
- 整个物理参数单元拆分 TRAIN/TEST；所有链均留在同一 split，不将耦合、动作或诊断数组输入模型。
- 唯一尺度单位 s=sqrt(mean(TRAIN microscopic phi²))，在训练前冻结。不是逐条件归一化，也没有使用测试数据或临界位置选定坐标。
- 新随机初始化、无预训练，Q/C/R 各 fresh Adam(.001)，constant LR，各固定 3000 次更新。batch8 个物理系综、每系综 64 构型；两个目标尺度均等权。

## 连续场适配的明确差异

C 的条件分布是 N(mu_theta(V),(.1s)²)。mu 是共享的 9→96→96→1 MLP，对输入使用 V/s，输出乘 s；不是平均核或 decimation 初始化。方差固定，防止通过放大随机噪声代替保留输入信息。没有二值化、裁剪、按样本换 seed 或对称翻转增强。

C 的信息项是**完整缓冲壳层的核平滑分箱信息代理**，并非旧二值精确经验 Shannon MI，也不是 InfoNCE。微观每系综随机取 128 个 3×3 可见块及 buffer=1 的 7×7 外围完整 24 点壳层。环境按固定 s 标准化，使用 24 维均方距离的 Gaussian 核，bandwidth=1，自点排除、行归一得到 W。固定噪声 Gaussian C 在 16 个固定分箱上的概率由解析 CDF 得到；原始边界 linspace(-3s,3s,17) 的两端替成无穷，故有限内边界为 ±2.625s。

定义 P_j 为第 j 个可见块的输出分箱概率，q_i=sum_j W_ij P_j，m=mean_i q_i，信息代理为 mean_i KL(q_i||m)，单位 nats。它含有限样本、带宽和平滑偏差，不能冒称真实长程互信息；全壳层使用不意味着高维密度已被准确估计。

C loss=-2×信息代理+2×逐系综方差下限+1×均匀幅度保持。方差下限比较 mean-C 输出与 detached 输入的标准差，按 s 归一并取 hinge²，Gaussian 噪声不计作防塌缩。均匀幅度探针 a/s=-2,-1,0,1,2，目标为保持 a；loss=.5 mean((mu(a,…,a)-a)/s)²，相当于固定方差 Gaussian NLL 去常数再乘 noise_ratio²。这是固定幅度单位的一项先验，不宣称精确 RG 的所有粗粒化都必须满足。

Q 的目标是连续场软局部统计，而不是二值 3×3 motif 全表：5 个固定 Gaussian soft bins（中心 -2,-1,0,1,2，宽 .5，均以 s 为单位）的单点概率及水平、竖直、两条对角相邻对分布。共 105 维，五组各单位质量、拼接后除 5。所有尺度共享。Q 从统计输出 g，affine decoder 的列按单位范数归一，无 PCA 初始化或强制满秩。

Q loss=10×三尺度重构均值+20×微观两半子集一致性+5×粗尺度两半一致性均值。训练 direct g 是两半 Q 的平均，不等于 Q 的全样本统计；评价同时保留两种估计器。R loss=5×两个单步闭合均值+5×微观起点两个 rollout 目标均值。

Q 的所有构型/统计输入均 detach，R 的 g 输入/目标均 detach。先分别求出 Q、C、R 梯度，再分别更新，防止参数更新顺序或图共享导致串流。C 不接受 Q 或 R 目标的梯度。

## 执行与限制

独立入口为 `python -m experiments.phi4_qcr`。父程序 `python -m scripts.run_phi4_qcr` 按资源门控→采样短预检→正式采样→独立训练耗时预检→正式 3000 步→只读数组报告执行。预检模型和构型不是正式科学结果，不复用其权重。GPU 固定为 225 的物理 GPU2，使用前两次间隔至少 10 秒检查；不干预他人进程，资源不足只等待。

默认门控预算为 CPU7200 核秒、GPU1800 卡秒、自身 GPU 峰值8GiB、实验目录1GiB。投影不通过保留状态并等待用户，不减样本或步数凑完成，不自动恢复、重跑或改配置。新实验/部署目录单独建立，启动后源代码冻结，不覆盖历史结果。

正式报告展示 R(g)、真实位移 R(g)-g、r→g 的尺度映射及损失。低闭合损失、插值零点或全局相似曲线不保证正确物理相变；单 r 家族和一维表示可能不闭合。有限链诊断不证明平衡；所有热/冷初态、ESS、接受率与符号混合警告都保留。数值不动点不自动认定物理临界点，thermal_nu 始终 null。
