# 仅执行高 k 加权训练

用户明确要求“直接进行改权重分布的训练”。本次只执行 `(0.2, 1.8)` 高 k 加权组的 fresh 无监督 Q/C/R 训练，固定 6000 步；不重跑等权组，不扩大原 3600 卡秒预算。

数学目标、梯度路由及原始配方沿用已经通过测试的尺度权重实现，见 [尺度权重定义](closure_scale_weighting.md)。两个尺度的单步和微观起点 rollout 都按权重和归一化。高 k 的 rollout 梯度仍通过其所有 R 调用；它不是冻结早期 R 调用。

复用 v1 已完成的 40 步执行预检的 JSON 计时，不读取其模型或优化器，不再测速。原预检卡时 41.152130860835314 秒及 CPU 用量计入原预算。一个正式训练与一个采集的保守总卡时投影约 2111.65 秒，低于 3600 秒。旧 v1 保持原样，以新的 v2 输出和冻结代码快照执行，禁止自动续训或重试。

仅复用已校验新数据、配对身份、数据统计缓存。最近已完成的同配方 v4 等权 6000 步模型仅作为历史参考；读取其已有公共 JSON/NPZ，不改写元数据，不伪造成新训练的配对对照，不额外推理旧模型。最终检查 Q/C 指纹和编码是否相同，再限定比较口径。

无新增物理采样、K 监督、未来物理预测损失或根搜索。仍输出未加权逐路径误差、中文损失曲线、R(g)、真实 R(g)-g 箭头及耦合到 g 映射；热指数不自动认证。固定 cuda:2、单 CPU 线程、nice=10；每 GPU 阶段保留原有资源等待门槛，不干预其他进程。
