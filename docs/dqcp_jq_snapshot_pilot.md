# J–Q 自旋快照 QCR：首轮可行性检验

目标是检验现有 QCR 能否从量子模型的无耦合标签自旋测量系综中学习相结构和一致的尺度流。数值根或分界本身不证明解禁闭，不将该试验称为恢复完整量子 RG。

## 模型与输入

使用二维方格、周期边界、偶数边长的自旋 1/2 J–Q2 模型：

`H = -J Σ_b P_b - Q Σ_□(P_bottom P_top + P_left P_right)`，`P_ij=1/4-S_i·S_j`。

固定 `J+Q=1`，扫描 `q=Q/(J+Q)`。SSE 量子蒙卡产生 `2 Sz=±1` 的空间快照；它们不是经典 Ising 的玻尔兹曼样本。训练不读取 q、能量、交错磁化或二聚体诊断。保存的 q 只用于划分整参数留出和事后评价。

当前试探规模：`L=18`、`β=18`；三个点额外进行 `β=36` 的独立诊断。每个生产条件四条独立链，随机／Néel 初态各两条，每链预热 4096 个 SSE sweep，间隔 32 sweep 保存 128 张快照。这里 sweep 指完整对角更新及所有闭合 loop 更新，不是逐自旋扫描。训练 q 为 `[0,.5,.8,.9,.94,.96,.98,1]`；留出 q 为 `[.7,.92,.95,.97,.99]`。

SSE 使用 Marshall 变换后的非负顶点权重；原始 Sz 测量不作交错符号变换。对角插入／移除更新整个 J 或 Q 算符，Q 的两个投影子顶点保留共同算符身份。只在预热调整算符串容量；生产若接近截断，停止并保留错误。实现以 L=2 的完整量子热分布、能量、交错磁化平方作独立精确对角化对照；L=2 的周期边界明确是多重边约定。该测试不认证较大系统的平衡。

## 进入训练前

检查能量、交错磁化平方和快照二聚体代理量的链间一致性、split Rhat、初始正序列 ESS，以及 β 加倍变化。`D_z` 由交错的 `Sz_i Sz_j` 构成，是单测量基代理量，不称为完整 SU(2) VBS 序参量。方向锁定也记录；能量稳定不能替代 VBS 混合检查。

任何保存诊断的每链 ESS 小于 32 或 split Rhat 大于 1.1（或不可计算）时，采样结束标记 `quality_hold`，不自动增加样本或训练。β 检查是诊断，不据一次比较宣布基态收敛。首轮采样主动墙时上限 1200 秒；到达后保留已完成结果，不自动恢复。

## QCR 预备设置

沿用最近双 Ising／Ising KB 使用的弱 KL 系综 VAE Q，`d_g=2`；随机、可训练的概率 C，`b=3`。接口检查确认现有最粗格点下限为 4，因此不使用原拟议的 `18→6→2`；18 格点只用于采样可行性，正式 QCR 使用 `36→12→4`、`β=36`，并诊断 `β=72`。C 保留经验直方图全壳层 MI、系综方差下限、保色项；Q/C/R 独立梯度。R 使用等目标尺度的 all-start-anchor，3000 次联合更新，然后冻结 Q/C，在固定 TRAIN 缓存上继续同一 R 和 Adam 至平台或额外 10000 次上限。无耦合监督，无新 DQCP 定制 loss。

两个潜变量不代表已经得到两个独立物理扫描方向；本轮只有一条 q 扫描线。最粗尺寸依然有限，本轮无法认证普适指数或连续／弱一级转变。如果快照、表示或流场显示信息不足，应先说明失败所在，不能凭增加潜空间维数就宣称恢复 DQCP。

## 已检出的采样瓶颈与修正

第一批 L=18 数据触发 18 项警告，均来自有符号二聚体方向的有效样本数或链间差异；能量、交错磁化平方和二聚体幅度通过同一门槛。原始结果与源码副本完整保留，不用于正式训练。

第二版每 8 个 SSE sweep 对整套自旋及算符串施加一次随机晶格平移或 90 度旋转。它是各向同性周期 J–Q 哈密顿量的精确对称变换，权重不变、接受率为 1；Q 子顶点索引也同时映射。它有意混合对称等价的 VBS 方向，并不解决非对称等价状态之间的慢混合。两版随机流不同，因此不能把差异全归因于对称更新做严格配对统计。第二版还将预检／生产／条件／β／链的随机流显式分离。加入对称操作后的完整热分布再次通过精确对照。

正式 L=36 计划采样最多 7200 秒单 CPU 线程，联合训练、末尾 R 与报告合计最多 1200 秒主动墙时；等待空闲 GPU 不占卡。数据质量未通过时保留结果并停止在训练前，不自动减采样、改 loss 或重跑。

第二版 L=18 预检已完成：13 个参数条件、52 条独立生产链，全部通过上述有限链门槛，最小 ESS 约 39.3，最大 split Rhat 约 1.024。它不是 L=36 或基态极限的保证。原采样版与加入对称更新版合计 10 项针对精确分布、几何映射和路径闭合的测试通过。合成随机数据上的 2 次联合更新与 2 次末尾 R 更新执行检查通过；这些更新不属于物理结果。

训练完成应输出各尺度 R(g)−g 灰度箭头、q 着色实际数据点、q→g、loss、联合与末尾 R 的闭环误差及数值不动点。不为潜空间任意根反推 q_c，不把外推根当作物理相变证据。
