# 无标签的未来尺度物理预测损失

这个可选约束检验：表示 `g=Q(D)` 除了重构局部 motif，是否还能保留预测更粗尺度物理量的信息。它是有限观测量上的自监督检验，不是完整 RG 充分性的证明，也不保证临界点或临界指数正确。

## 损失与信息边界

令同一制备条件下独立生成的两条物理链为 `A`、`B`，`D_s^A` 为链 `A` 在尺度 `s` 的构型系综，`U_j(D_t^B)` 为另一条链在未来尺度 `t>s` 的物理观测量。默认三条路径为 `0→1`、`1→2`、`0→2`：

\[
L_{\mathrm{future}}=
\frac{1}{|\mathcal T|J}
\sum_{(s,t)\in\mathcal T}\sum_{j=1}^{J}
\mathbb E_{A\ne B}\left[
\left(\frac{F_{s\to t,j}(Q(\operatorname{stopgrad}D_s^A))
-\operatorname{stopgrad}U_j(D_t^B)}{\sigma_{s\to t,j,\mathrm{TRAIN}}}\right)^2
\right].
\]

每条路径使用独立的 `hidden=32`、`tanh` 辅助预测头 `F`。实现中预测头输出标准化目标；上式的物理单位输出等于 `均值 + 标准差 × 预测头输出`。路径、观测量和物理链等权平均，配对双向使用。

- 不使用 `K`、扰动耦合、`Kc`、临界指数或理论特征值作为输入、目标或配对依据。条件 ID 只检验两条链来自同一制备条件，不进入神经网络或损失数值；这需要制备分组信息，并非无分组数据学习。
- 配对 JSON 绑定数据 SHA，给出不重叠的同条件、不同链配对；TRAIN/TEST 物理链也不重叠。不同 ID 本身不能证明统计独立，独立性必须由采样来源保证；同一链的两个构型或两次 C 抽样不能冒充两条独立物理链。
- 新损失只更新 `Q` 和 `F`。在已有粗粒化轨迹上先分离 C 的计算图，再重新计算 Q；物理目标也分离梯度。它不调用 R，不向 C/R 回传梯度，不额外抽取 C 轨迹。C 原有 MI/方差/颜色目标和 R 原有闭合目标保持不变。

## 当前物理观测量与归一化

预测框架可以接受不同物理系统的观测量适配器，但当前适配器仅支持周期边界、单通道、二值二维正方晶格，要求各目标尺度 `L≥12` 且能被 6 整除。五个目标是：

1. 距离 `L/6`、`L/3` 的轴向两点关联，分别对两个轴平均。
2. 最低和第二非零轴向结构因子，分别对两个轴平均。
3. 最低对角结构因子，对两个对角方向平均。

结构因子采用 `S(q)=|Σ_x s_x exp(iq·x)|²/N_sites²`，不包含零模。关联和结构因子先逐构型计算，再在物理链内平均。它们是有限的长程物理信息探针，不是适用于所有系统的普适完备集合；不支持的系统需要明确选择新的适配器。

新二维 QCR 沿用默认非重叠 `3×3`、步长 3、schema 5 和随机初始化的可训练 C。本适配器可用于 `108→36→12`；不能直接用于末尺度为 4 的 `36→12→4`。采用相对距离是为了避免末尺度的固定 `r=4/8` 周期别名，因此这里不是历史固定距离诊断的原样复现。

本次约定仅在初始随机 C、零参数更新时，用全部 TRAIN 物理链和 5 次 C 抽样校准 `[3,5]` 目标均值/标准差；标准差在物理单位下取下限 `0.01`。这些数值及来源指纹保存后冻结，不随训练中的 C 改变，也不使用 TEST 校准。`0.01` 是本次数值尺度约定，不是物理定律。训练每步复用已有的一次 C 轨迹，是随机目标的单次抽样估计，不等于每步平均 5 次。

同时记录标准化 MSE/NRMSE 和物理单位 MSE/RMSE及逐路径误差，避免仅因固定分母而误解随 C 变化的目标。不同观测量的混合总误差仅是摘要，不能替代逐项物理检查。

## 显式启用与执行选项

默认 `--q-future-weight 0` 不创建辅助预测头、不改变原采样流程，也不新增前向计算或随机抽样。以下为启用示例；配置中的数据及两个 JSON 必须满足上述指纹、几何和来源约定：

```sh
python -m experiments.rsmi_separate_qcr \
  --config path/to/config.json \
  --output path/to/new_run \
  --q-future-pairs path/to/pairs.json \
  --q-future-normalizer path/to/normalizer.json \
  --q-future-weight 1
```

公平配对采样对照使用 `--q-future-control --q-future-pairs ...`，保持未来损失权重为零且不创建预测头。辅助预测头与归一化状态单独保存；精确续训要求保留配对、归一化和执行约定。不要通过开启旧配方许可来绕过检查。

CUDA 执行可显式加 `--mi-test-cpu`：完整 TEST 经验直方图 MI 在 CPU 上计算，不抽子集、不替换估计量；TRAIN MI 及其梯度仍在原设备上。TEST 使用分离梯度后的 C 概率表，不能参与训练。该选项只改变执行位置；CPU/GPU 归约可能有末位数值差异，耗时也可能变化。

优化 CUDA 路径中的未来预测 Q 前向按物理链轴分为最多 4 条链的小块，复用同次新建的模式表；每条链的全部样本完整保留，不拆 C 抽样，也不先平均非线性 Q 的输出。此执行约定及可信二值检查标志写入回执，精确续训不能切换。数学目标与一阶梯度不变，浮点聚合末位可能不同；默认 CPU、reference 和零权重路径保持原实现。

## 尚未证明的结论

历史监督/无监督表示的相关诊断在允许 TRAIN 拟合读出、消除坐标差异后，没有显示稳健的“监督好、无监督差”优势，不能据此声称本损失已找到指数偏差的原因。当前新训练是对未来尺度信息约束的检验，而不是已证明有效的纠偏方法。最终仍需检查独立 TEST 物理预测、R 闭合与响应、有限尺寸效应及热方向识别；单独降低此损失不足以认证临界指数。
