版本：2026-10-24。本文档是写作与实验规划，不是启动、续训、迁移或修改任何实验的指令。已冻结的配置、历史结果和正式报告均保持不变。

## 1. 论文定位与证据主线

核心问题：能否从无耦合、温度、相标签的构型系综中，同时学习局部随机粗粒化 C、共享系综坐标 Q 和跨尺度自治映射 R，形成可检验的有限尺度有效描述？

实验叙事按下列顺序展开，而不是按实验目录的时间顺序罗列：

1. 能学到：表示包含可读出的统计信息，R 能预测实际 C 产生的尺度变化。
2. 多参数仍有效：不只重编码一条温度曲线，也能处理 K–B 条件族与较高维 g。
3. 能推广：冻结同一 Q/C/R 后，检验未训练参数条件、初始尺寸和 RG 深度。
4. 为什么有效、是否稳定：用配对消融、容量对照和多 seed 检验。
5. 边界在哪里：区分采样、信息估计、表示不足、流拟合不足及物理解释限制。

主张限于无标签系综上的有限尺度表示与流学习。精确临界指数、完整有效 Hamiltonian 恢复、任意深度 RG 和一般自旋玻璃相发现，不作为尚未验证的统一承诺。

## 4. 实验小节一：设置、划分与比较方法

### 4.1 共同训练约定

- 默认随机初始化 Q/C/R；C 为随机可训练概率核，无选核、固定核或预训练。
- 一维使用两点块、stride 2；新二维默认非重叠 3×3、stride 3、schema_version 5。三维 b=2 作为明确规格单独报告。
- C 目标：−2×微观尺度 buffered full-shell 经验 MI + 2×逐系综方差下限（ratio 1）+ 1×均匀块保色 NLL，buffer=1。
- Q 默认共享仿射 motif 重构（权重 10）及微观/粗尺度子集一致性（有效权重 20/5）；解码器列单位范数，不强制满秩，无 PCA 初始化。
- 同时独立梯度：Q 只收表示目标，C 只收其自身目标，R 只收一步/微观起点多步闭合目标；R 不更新 Q/C，Q 不更新 C。
- 两条闭合分支分别对目标尺度均匀平均。不将历史非均匀权重、future loss 或 response loss 变成默认设置。
- 报告固定实际更新数、学习率策略和最终检查点；不按理论 Kc、指数、根形态或 TEST 误差挑选早停点。
- 历史不同几何、block、估计器和梯度路线保留原标记。复验改变配方时应称新对照，不称严格复现。

### 4.2 数据与统计划分

- 无标签不等于无系综分组：同一准备条件的构型属于同一系综；数值 K/T/B 只用于生成与事后评价。
- 区分完整参数条件留出与独立物理链留出；不把同一相关链的构型拆分叫独立数据。
- 多次 C draw 不增加独立物理链数。误差与区间以物理链为统计单位，明确 C 内平均次序。
- 所有方法共享可比的数据视图、留出条件与评价预算，记录真实数据和代码指纹。
- 多训练 seed 只衡量优化与初始化随机性；独立物理采样复验另列。

### 4.3 基线分层

| 比较组 | 目的 | 公平性要求 |
|---|---|---|
| 恒等映射 | 排除几乎没有尺度变化也能获得小误差的解释 | 与 R 使用同一直接编码、同一 C draw、同一评价路径 |
| TRAIN-only PCA + 回归流 | 检验复杂表示是否优于简单统计压缩 | 统计输入、读出预算与拟合范围说明清楚；PCA 仅在 TRAIN 拟合，属于独立基线而非默认初始化 |
| 固定 decimation/majority + 其余学习模块 | 隔离学习 C 的贡献 | 明确是固定核消融；C 改变后实际粗粒化目标也改变，不能仅按潜坐标 loss 排名 |
| Neural MCRG | 任务级 RG 学习比较 | 说明算符截断、逐状态拟合、数据与计算预算，不假定与 QCR 输出结构完全相同 |
| RSMI + 明确的坐标/流读出 | 信息粗粒化与流重建比较 | 不只比较 C；温度标定、逐尺度重训及适配成本均须公开 |
| 带耦合标签的 QCR | 额外信息参照 | 单独列为有标签设置；不是严格性能上界，不混入无标签排名 |

已知 action/score 的方法另设信息权限列，不与纯构型输入直接混排。无相标签、无耦合标签与无需 action 是三种不同约束。

文献入口：[Neural MCRG](https://arxiv.org/abs/2010.05703)、[RSMI](https://arxiv.org/html/1704.06279v2)、[Learning of Statistical Field Theories](https://arxiv.org/html/2511.09859v1)。具体实现与新增预算仍需另行确定。

### 4.4 主要评价指标

1. Q 的直接统计重构，以及固定读出 D(R^k(g0)) 的实际统计预测误差。
2. 各条一步与 rollout 路径的绝对 RMSE、原 TRAIN 目标标准差 NRMSE；保留恒等映射基线。
3. 参数–g 对应关系、TRAIN PCA 谱、主要成分上的 R(g) 与真实位移 R(g)−g。
4. 完整坐标数值根、全 Jacobian 谱、实际残差、支持诊断与非穷尽搜索限制。
5. 训练/采样随机性、采样诊断和分阶段资源成本。

不同 Q 的坐标误差不作为坐标不变的跨方法排名。跨方法应优先比较定义可对齐的物理统计与预测任务；不能假定不同 C 定义同一个物理 RG 算符。局域 motif 是当前直接读出指标，不冒充长程相关的完整验证。

## 5. 实验小节二：有限尺度流学习与跨问题验证

核心问题：框架能否学习含物理信息的表示，并预测实际 C 产生的尺度演化，而不只是形成好看的相分类图？

- 二维 B=0 为主：当前规格 d_g=5、108→36→12、hidden 96、局部特征数 12、固定 12000 次更新。
- 展示全部预定 seed 的预测表现与候选结构，不只展示 seed91 或最接近理论结果的一次。
- 一维经典 Ising 提供受控流向与端点检查。解析 decimation 是参考变换，不是任意学习 C 的精确真值；学习 C 应与其实际生成统计对应。
- 三维 Ising 以显式 16³→8³→4³、b=2 的现有规格为起点，披露有限尺寸、单 seed 与 MI 偏差。
- Potts 如纳入则同时报告 q=3/q=8；数值根本身不足以证明一阶机制或其标度规律。

## 6. 实验小节三：多参数条件与高维表示

核心问题：能否处理 K–B 条件族，而非仅将单参数温度曲线编码到更高维？

- 利用已有二维 K–B、b3、d_g=5/10 的完整报告；补多训练 seed 时固定数据、更新数、模型主体和目标。
- 报告参数条件对应关系、TRAIN 前导成分占比、一步与两步预测，并检查两种物理变化是否在表示中保留。
- 核查对称性处理是否消除了 +B/−B 的区别。对称商空间与原物理空间必须明确区分。
- 将 d_g 与 Q 内部容量分开：较大输出维数不自动增加可辨识物理方向。
- 独立偶耦合（如次近邻 K2）可作为后续机制验证，未授权启动；检验离开最近邻微观族后的共享坐标与闭合，而非再增加一个相似温度扫描。

主图：PC1–PC2 流场，配参数着色/对应关系和投影残差诊断。

解释边界：PCA 方差集中不等于证明物理耦合维数；投影零点不等于完整坐标根；完整数值根也不自动有物理支持。目前 K–B 的结论定位为多参数几何与有限尺度闭合，不预写完整相图恢复。

## 7. 实验小节四：尺寸与深度泛化

冻结同一个已训练 Q/C/R，不重新训练、重拟合读出或挑选测试点。分开三个测试轴：

| 测试轴 | 保持不变 | 变化内容 |
|---|---|---|
| 参数条件留出 | 训练尺寸与深度 | 未参与训练的完整准备条件 |
| 尺寸外推 | 已训练 RG 深度 | 未训练的更大初始尺寸，例如冻结模型上的 1080→360→120 |
| 深度外推 | 明确的初始尺寸与固定模型 | 额外 RG 步，例如 108→36→12→4；大尺寸链的 120→40 单列 |

- 比较直接观测 Q(C^k D) 与真正预测 R^k(Q(D))，以及固定读出的局域统计预测。
- 将统计误差分解为表示/读出误差与 R 传输误差；平方误差还含交叉项，不能简单相加 RMSE。
- 更大尺寸不自动消除采样偏差；小末端格点的有限尺寸效应也不能全部归因 R。
- 如检验长程统计，须有明确冻结读出和独立评价，不能把直接 C 构型的相关函数当成 R 的预测。
- 现有少链 1080 探针是探索性证据，不能替代统一、多链的正式泛化验证。

主图：预测误差随深度与实际尺度变化，以及选定统计量的预测—直接测量对照。构型可视化为辅助，且标为 C 的输出，不是 R 生成。

## 8. 实验小节五：消融、容量与鲁棒性

主要消融集中于二维 B=0，避免在每个模型重复完整网格。

### 8.1 多 seed

- 完整报告预定训练 seed91–95；不平均不同 seed 的原始 g。
- 汇总各 seed 预测误差、表示谱、完整根和支持诊断；候选根检出与物理认证分开统计。
- 除平均值/离散程度外保留每个 seed；不把五个训练 seed 当五份独立物理数据。
- 披露 seed91 使用 GPU1、后续 seed 使用同主机 GPU0 的既有硬件差别。

### 8.2 核心目标去项

按既有阶段 B 登记方案，用配对 seed91/92/93，各次只删除一项：

1. C 的 MI 项。
2. C 的逐系综方差下限项。
3. C 的均匀块保色项。
4. Q 的仿射重构项。
5. Q 的子集一致性项。
6. R 的微观起点多步闭合项。

不同时改变容量、数据、学习率或终点。核对初始化指纹以确认真正配对，而不仅依赖 seed 编号。梯度路由对照可登记为第二轮机制验证，不能默认为已授权运行。

### 8.3 容量与结构

- Q 局部特征数 12/24/48，hidden 96、C/R 主体与其余目标固定。
- d_g 对照与特征数对照分开。已有 b2 高维实验是历史证据，不直接与 b3 结果作输出维数的因果比较。
- d_g=100 保留为用户指定的过参数化检查；披露局部特征和 R 隐层的结构瓶颈，不把数值中性/弱方向当物理模式。
- 尺寸与训练深度消融分开：固定深度比较尺寸，固定初始尺寸比较深度，不将二者同时变化归为一个因素。
